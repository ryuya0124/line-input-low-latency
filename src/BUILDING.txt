Line Input Monitor 0.3.1

Run MSBuild.exe Build.proj from the repository root on Windows.
MSBuild.exe is available in Windows\Microsoft.NET\Framework64\v4.0.30319.
Requirements: Visual Studio Desktop C++ tools, Windows SDK, .NET Framework 4.8.

Build.proj directly launches csc.exe to compile BuildTool.cs and IconBuilder.cs.
BuildTool.exe directly launches cl.exe and csc.exe without a command shell.
No Node.js, Python, PowerShell script files, batch files, or cmd scripts are used.

Native programs: AudioEngine.cpp and AudioSettings.cpp.
UI: App.cs, MainWindow.cs, Common.cs, DeviceSettings.cs, Theme.cs, AssemblyInfo.cs.
Installer/uninstaller: Installer.cs and the same shared C# files.
Icons are generated by IconBuilder.cs; app.svg is its source design.

The build validates the installer payload, generates dark/light screenshots,
and writes Setup.exe, a complete source ZIP, and SHA256SUMS to build/dist.
Hardware audio behavior requires testing on a physical Windows machine.
